# ADR-005: Cost Optimisation Strategy

## Status
Accepted

## Date
2026-09-08

## Context
While functionality and security are paramount, cost efficiency must also be considered during infrastructure design. This involves selecting appropriate instance types and service configurations.

## Decision
The current configuration aims for a balance between performance, security, and cost, resulting in an estimated total cost of $788.17/month. Specific cost optimisation measures such as Graviton instance adoption or right-sizing are not explicitly detailed in the provided blueprint or cost estimate, suggesting a baseline configuration was prioritised.

## Consequences
- **Positive**: Provides a functional and secure environment within an estimated budget.
- **Negative**: Potential for cost savings may exist through further optimisation (e.g., Graviton instances, reserved instances, detailed right-sizing) that has not yet been applied.
