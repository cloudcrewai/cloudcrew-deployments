# ADR-004: Cost Optimisation Strategy

## Status
Accepted

## Date
2026-09-08

## Context
The data platform's operational costs need to be managed effectively while ensuring performance and availability targets are met for the production environment.

## Decision
The current configuration reflects a balance between performance, availability, and cost. Specific instance types and managed service configurations were chosen based on the projected workload requirements. The total estimated monthly cost is $1518.83.

## Consequences
- **Positive**: Provides a predictable cost baseline for the production environment.
- **Negative**: Continuous monitoring and potential future right-sizing may be necessary to optimize costs as usage patterns evolve.
