## Rollback Procedures

### Option 1 — Revert via Git (Recommended)

```bash
# 1. Identify the previous known-good commit
git log --oneline

# 2. Revert to previous IaC version
git revert HEAD

# 3. Open a new PR with the revert
# 4. Approve and merge through your CI/CD pipeline
```

### Option 2 — Terraform Destroy (Full teardown)

```bash
# ⚠️ This will DESTROY all resources. Use only as last resort.
terraform init
terraform plan -destroy -out=destroy.tfplan
# Review destroy.tfplan carefully before proceeding
terraform apply destroy.tfplan
```

### Option 3 — Targeted Resource Rollback

```bash
# Destroy a specific resource only
terraform destroy -target=<resource_type>.<resource_name>

# Example:
terraform destroy -target=aws_ecs_service.app
```

## State Management

```bash
# List all resources in state
terraform state list

# Remove a resource from state without destroying it
terraform state rm <resource_address>

# Pull current state
terraform state pull > current.tfstate
```
