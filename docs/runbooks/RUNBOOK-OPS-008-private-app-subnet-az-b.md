## Overview
Private App Subnet AZ-B is a network segment within the App VPC in Availability Zone B, designed to host application resources such as ECS tasks or EC2 instances. It does not have direct internet access.

## Prerequisites
- AWS CLI configured with appropriate permissions
- IAM user or role with EC2 network management privileges

## Architecture
Located in Availability Zone B, this subnet is configured to route outbound internet traffic through the NAT Gateway in AZ-B. Inbound traffic is typically managed via a load balancer or other ingress controls.

### Common Issues
### Application instances cannot reach the internet for updates or external services
Diagnosis: Verify the route table associated with this subnet has a default route (0.0.0.0/0) pointing to the NAT Gateway in AZ-B. Check NAT Gateway status and Security Group/Network ACL rules.
Resolution: Correct the route table configuration. Ensure the NAT Gateway is functional and firewall rules allow necessary outbound traffic.
