# Runbook: API Gateway HTTP API

## Overview
The API Gateway HTTP API serves as the entry point for all incoming requests to the serverless backend. It routes requests to the appropriate Lambda function based on the defined routes and integrates with Cognito for authentication.

## Prerequisites
- AWS CLI configured with appropriate permissions
- IAM permissions to manage API Gateway, Lambda, and Cognito.
- Access to the AWS console.

## Architecture
An HTTP API Gateway is configured with a custom domain name, integrating with the Lambda API Handler. It uses Cognito User Pools for authentication and authorization.

## Operations

### Scaling
1. Navigate to the API Gateway console.
2. Select the specific HTTP API.
3. Configure stage settings and auto-scaling parameters if available for HTTP APIs (note: HTTP APIs scale automatically based on demand).
4. For throttling limits, navigate to Usage Plans and API Keys.

### Monitoring
Key metrics to monitor in CloudWatch: 
- `Count` (total requests)
- `4XXError` (client-side errors)
- `5XXError` (server-side errors)
- `Latency` (request processing time). 
Recommended alarm thresholds: `5XXError` > 5 in 5 minutes, `Latency` > 1000ms P90 for 5 minutes.

### Backup & Recovery
API Gateway configurations are managed via Infrastructure as Code. In case of accidental deletion or misconfiguration, the API Gateway can be recreated by re-applying the IaC.

### Common Issues
### API returns 5xx errors
*   **Diagnosis**: Check CloudWatch logs for the integrated Lambda function for unhandled exceptions or errors. Verify API Gateway execution role permissions.
*   **Resolution**: Debug the Lambda function, fix the error, and redeploy. Ensure the API Gateway has necessary permissions to invoke the Lambda function.

### Requests are unauthorized
*   **Diagnosis**: Verify that the client is correctly passing authentication tokens (e.g., JWT) in the request headers. Check Cognito User Pool configuration and associated authorizers in API Gateway.
*   **Resolution**: Ensure correct token format and validity. Review Cognito User Pool settings and API Gateway authorizer configurations.

## Rollback Procedure
1. Revert the IaC commit that modified the API Gateway configuration.
2. Apply the reverted IaC using `terraform apply` or equivalent.
3. Verify the API Gateway endpoints and integrations are restored to the previous state.
