### Monitoring
Key metrics: Subnet traffic flow through VPC Flow Logs. Monitor for unusual ingress/egress patterns. Ensure no critical application resources are directly exposed unless intended and secured.

### Backup & Recovery
Subnets are logical constructs within a VPC. Recovery from accidental deletion involves recreating the subnet definition in Infrastructure as Code and applying it. Associated resources (like NAT Gateways) have their own recovery procedures.

### Common Issues
### Resource Unreachability
- **Diagnosis**: Incorrect route table configuration, Security Group or Network ACL rules blocking traffic.
- **Resolution**: Review and adjust route tables to ensure proper routing to the Internet Gateway. Verify Security Group and Network ACL rules for the resources within the subnet.

## Rollback Procedure
1. Revert the Infrastructure as Code changes related to the public subnet.
2. Apply the reverted configuration using Terraform.
3. Verify network connectivity to and from resources within the subnet.
