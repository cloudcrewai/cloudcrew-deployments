## Operations

### Scaling
Subnet capacity is determined by the CIDR block size. To 'scale' subnet capacity, you would typically create additional subnets or adjust CIDR ranges if feasible and planned.

### Monitoring
Monitor Network In/Out for resources within this subnet. Track traffic flow through associated route tables.

### Backup & Recovery
Subnets are network constructs within a VPC and are not directly backed up. Their configuration is part of the VPC's state. Recovery involves recreating the subnet with the same CIDR and route table associations if the VPC itself needs to be re-established.

### Common Issues
### Resources in this subnet cannot be reached from the internet
- **Diagnosis**: Verify that the subnet's route table is correctly associated with the Internet Gateway. Ensure security groups and Network ACLs allow inbound traffic on the desired ports.
- **Resolution**: Confirm route table association with IGW and adjust Security Group/NACL rules.

### Resources cannot reach the internet
- **Diagnosis**: Check the route table for outbound traffic (e.g., `0.0.0.0/0`). Ensure it routes traffic to the NAT Gateway for private subnets, or directly to the Internet Gateway for public subnets that require outbound access.
