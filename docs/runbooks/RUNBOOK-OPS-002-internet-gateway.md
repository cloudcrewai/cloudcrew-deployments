# Runbook: Internet Gateway

## Overview
The Internet Gateway (IGW) allows communication between resources within the VPC and the public internet. It is essential for services that need to access external resources or be accessed from the internet.

## Prerequisites
- AWS CLI configured with appropriate credentials.
- IAM permissions to describe VPC and Internet Gateways.

## Architecture
Attached to the 'App VPC' (10.0.0.0/16), enabling communication between resources in public subnets and the internet. It does not reside in a specific Availability Zone.

## Operations

### Scaling
The Internet Gateway is a managed AWS resource and automatically scales to handle network traffic. No manual scaling is required.

### Monitoring
Monitor the attached VPC's network traffic metrics. CloudWatch metrics for IGW itself are limited; focus on the traffic flowing through resources it enables.

### Backup & Recovery
The Internet Gateway is a managed service. Its configuration is part of the VPC definition in the Infrastructure as Code. Redeploy the IaC to recreate it if accidentally deleted.

### Common Issues
### Resources in public subnets cannot reach the internet
Verify the VPC's main route table has a route for 0.0.0.0/0 pointing to the Internet Gateway. Check security groups and Network ACLs of the resources.

## Rollback Procedure
1. Revert the Infrastructure as Code commit that modified or removed the Internet Gateway.
2. Execute the IaC apply command.
3. Verify internet connectivity for resources in public subnets.
