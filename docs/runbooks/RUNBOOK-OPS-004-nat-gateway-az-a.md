# Runbook: NAT Gateway AZ-A

## Overview
A NAT Gateway enables instances in a private subnet to connect to the internet or other AWS services, but prevents the internet from initiating a connection with the instances. This NAT Gateway is deployed in Availability Zone 'a'.

## Prerequisites
- AWS CLI configured with appropriate permissions.
- IAM user/role with EC2 read/write access.
- An Elastic IP address.
- A public subnet.

## Architecture
Located in 'Public Subnet AZ-A' ('10.0.1.0/24'), this NAT Gateway allows resources in the associated private subnets in AZ-A to access the internet while remaining inaccessible from the internet.

## Operations

### Scaling
For high availability and performance, a NAT Gateway is deployed per Availability Zone. Scaling NAT Gateway throughput is handled by AWS; if higher throughput is needed, consider alternative architectures or AWS documentation for scaling NAT Gateway performance.

### Monitoring
Key CloudWatch metrics: `BytesInFromSource`, `BytesOutToDestination`, `PacketsInFromSource`, `PacketsOutToDestination`. Monitor for high utilization or error rates.

### Backup & Recovery
NAT Gateways are managed AWS resources. They are inherently highly available within their Availability Zone. If a NAT Gateway fails, its replacement requires re-association of the Elastic IP. Recovery involves ensuring the Elastic IP is correctly associated with the new NAT Gateway.

### Common Issues
### Internet connectivity failure for private instances
- **Diagnosis**: Check NAT Gateway status in the VPC console. Verify the route table for the private subnet points to this NAT Gateway for `0.0.0.0/0` destination. Ensure the NAT Gateway has an associated Elastic IP.
- **Resolution**: If the NAT Gateway is in a failed state, re-create it. Ensure correct route table configuration and Elastic IP association.

## Rollback Procedure
1. Revert IaC changes that created or modified the NAT Gateway.
2. Apply the reverted IaC.
3. If necessary, manually disassociate the Elastic IP and delete the old NAT Gateway before the new one is provisioned by IaC.
