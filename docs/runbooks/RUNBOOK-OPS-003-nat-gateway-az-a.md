# Runbook: NAT Gateway AZ-A

## Overview
The NAT Gateway in Availability Zone A enables instances in private subnets within AZ-A to connect to the internet or other AWS services, but prevents the internet from initiating connections with those instances.

## Prerequisites
- AWS CLI configured with appropriate permissions
- IAM user or role with EC2 network management privileges
- Elastic IP address associated with the NAT Gateway

## Architecture
Resides in a public subnet in Availability Zone A and is associated with an Elastic IP address. Route tables for private subnets in AZ-A direct outbound internet traffic through this NAT Gateway.

## Operations

### Scaling
NAT Gateways are AZ-specific. For high availability and to handle increased outbound traffic, multiple NAT Gateways can be deployed across different Availability Zones. Scaling is achieved by increasing the number of NAT Gateways and updating route tables accordingly.

### Monitoring
Key CloudWatch metrics include 'BytesInFromSource', 'BytesOutToSource', 'PacketsInFromSource', and 'PacketsOutToSource'. Monitor for high utilization which may indicate a need for scaling or network optimization. Also, monitor 'ActiveConnectionCount'.

### Backup & Recovery
NAT Gateway configurations are managed via Infrastructure as Code (IaC). Recovery involves re-applying the IaC configurations. The associated Elastic IP is a separate resource that needs to be managed within the IaC.

### Common Issues
### Private instances cannot access the internet
Diagnosis: Check route tables for the private subnet to ensure they have a default route (0.0.0.0/0) pointing to the NAT Gateway. Verify the NAT Gateway has an Elastic IP and is in a public subnet. Check Security Groups and Network ACLs.
Resolution: Correct route table entries. Ensure NAT Gateway is healthy and associated Elastic IP is correctly allocated. Review firewall rules.

## Rollback Procedure
1. Revert the IaC commit that modified the NAT Gateway configuration.
2. Apply the reverted IaC configuration.
3. Verify outbound internet connectivity from private instances.
