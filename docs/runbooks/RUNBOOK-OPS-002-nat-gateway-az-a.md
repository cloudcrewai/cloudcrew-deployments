# Runbook: NAT Gateway AZ-A

## Overview
The NAT Gateway in Availability Zone A enables instances in private subnets within the same AZ to connect to the internet or other AWS services, while preventing inbound connections initiated from the internet.

## Prerequisites
- AWS CLI configured with appropriate permissions
- Elastic IP address associated with the NAT Gateway
- Route table configured to direct traffic to the NAT Gateway

## Architecture
Resides in the public subnet of Availability Zone A. It routes outbound traffic from private subnets in AZ-A to the internet via its associated Elastic IP address.

## Operations

### Scaling
NAT Gateways are managed services that automatically scale their throughput capacity. For higher throughput requirements, consider provisioning additional NAT Gateways in different subnets or Availability Zones and adjusting routing accordingly.

### Monitoring
Key metrics to monitor include `BytesInFromSource`, `BytesOutToDestination`, and `ActiveConnectionCount`. Set alarms for sustained high utilization of these metrics, which may indicate a need for additional NAT Gateways or investigation into network traffic patterns.

### Backup & Recovery
NAT Gateways are managed AWS resources. Backup and recovery are handled by AWS. If a NAT Gateway becomes unavailable, traffic is rerouted to other available NAT Gateways (if configured) or fails over to a newly provisioned one.

### Common Issues
### High NAT Gateway latency or errors
**Diagnosis**: Monitor CloudWatch metrics for `BytesInFromSource`, `BytesOutToDestination`, and `PacketsDropCount`. Check associated route tables and security groups.
**Resolution**: If traffic volume exceeds capacity, provision additional NAT Gateways. Investigate application-level issues if metrics are nominal. Ensure route tables correctly direct traffic.

## Rollback Procedure
1. Revert the IaC commit that provisions or modifies the NAT Gateway.
2. Run `terraform apply` to remove the NAT Gateway.
3. Update route tables to point to an alternative NAT Gateway or handle the loss of connectivity.
