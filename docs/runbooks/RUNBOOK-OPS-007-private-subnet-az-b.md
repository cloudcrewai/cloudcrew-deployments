# Runbook: Private Subnet AZ-B

## Overview
The private subnet in Availability Zone B is a segment of the VPC network that does not have a direct route to the Internet Gateway. Resources within this subnet can only initiate outbound connections to the internet via a NAT Gateway.

## Prerequisites
- AWS CLI configured with appropriate permissions
- Route table configured to direct internet-bound traffic to a NAT Gateway

## Architecture
Located in Availability Zone B with CIDR block 10.0.12.0/24. This subnet hosts backend resources like application servers (ECS tasks) and databases that should not be directly accessible from the internet.

## Operations

### Scaling
The subnet's CIDR block is fixed. To scale the number of resources, additional private subnets can be created in the same or different AZs, provided the VPC CIDR allows. This requires updating route tables and ensuring NAT Gateway capacity is sufficient.

### Monitoring
Monitor IP address utilization within the subnet. Key metrics include `AvailableIpAddressCount`. Set alarms for low available IP addresses, as this can prevent new resources from launching.

### Backup & Recovery
Private subnets are logical constructs. Recovery involves ensuring the VPC and its associated route tables are correctly defined in IaC. If a subnet is deleted, it can be recreated using the IaC definitions, and resources redeployed into it.

### Common Issues
### Resources in private subnet cannot reach the internet
**Diagnosis**: Verify the subnet's route table is associated and has a route to the NAT Gateway. Ensure the NAT Gateway is healthy and has sufficient capacity. Check Network ACLs and Security Groups.
**Resolution**: Correct route table configuration. Troubleshoot NAT Gateway issues. Adjust Network ACLs or Security Groups if they are blocking outbound traffic.

## Rollback Procedure
1. Revert the IaC commit that modified the subnet or its associated route table.
2. Run `terraform apply` to restore the previous configuration.
3. Verify connectivity for resources within the private subnet.
