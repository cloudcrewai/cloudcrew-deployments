# Runbook: ACM Certificate

## Overview
AWS Certificate Manager (ACM) provides provisioning, management, and deployment of public and private SSL/TLS certificates for use with AWS services like Elastic Load Balancing and CloudFront.

## Prerequisites
- AWS CLI configured with appropriate permissions.
- IAM user/role with ACM read/write access.

## Architecture
The ACM certificate is associated with the application's domain name, enabling HTTPS communication for the 'three-tier-web-app'.

## Operations

### Scaling
ACM certificates do not require scaling. ACM handles certificate management and renewal automatically.

### Monitoring
Monitor certificate expiration dates. ACM automatically attempts to renew certificates that are managed by ACM and were validated using DNS.

### Backup & Recovery
ACM certificates are managed by AWS and are automatically backed up. If a certificate is deleted, it can be re-provisioned and re-associated.

### Common Issues
### Certificate validation failure
- **Diagnosis**: Ensure DNS records (if using DNS validation) are correctly created and propagated, or that the email validation process was completed.
- **Resolution**: Re-initiate validation. For DNS validation, check CNAME records. For email validation, check the registered email addresses.

## Rollback Procedure
1. If a new certificate was issued and associated, revert the association to the previous certificate.
2. If the certificate was deleted, re-request and re-associate the certificate.
