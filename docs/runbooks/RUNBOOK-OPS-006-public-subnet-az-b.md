## Operations

### Scaling

### Monitoring

### Backup & Recovery

### Common Issues
### IP Address exhaustion
Diagnosis: Monitor the number of available IPs in the subnet. If nearing capacity, investigate resource usage.
Resolution: Consider expanding the subnet's CIDR if the VPC allows, or create a new subnet within the VPC and update routing.

### Connectivity issues to/from public resources
Diagnosis: Verify route tables associated with the subnet. Check Network ACLs and Security Groups for resources within the subnet.
Resolution: Ensure correct routes are configured, and firewall rules permit desired traffic.
